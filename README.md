# TTO Trading

Türkiye makro & piyasa araştırmaları — projeler, canlı grafikler ve hesap araçları.

- **site/** — Astro ile üretilen statik site (Markdown içerik, KaTeX formüller,
  Plotly grafik gömme, istemci tarafı hesaplayıcılar).
- **Aktarılacak Projeler/** — siteyi besleyen Python veri hatları.
- **Research/** — ham araştırma dosyaları; olgunlaşanlar `site/src/content/arastirma/`
  altına Markdown olarak aktarılır.

Ayrıntılı çalışma rehberi: [CLAUDE.md](CLAUDE.md)

## Hızlı başlangıç

```bash
cd site
npm install
npm run dev
```
